## Ask it things like

> How many n11 orders came in this week, and how many are still being prepared?

> What was my n11 commission rate on last month's orders?

> Which n11 orders were cancelled this month?

No dashboard, no export, no query language. You ask in the assistant you already use and the answer comes back with the account it came from.

## Connect n11

**1. Open API Accounts in the Seller Office**

Sign in to the n11 Seller Office and open My Account → API Accounts. The page also links to SOAP documents; HeyMetra does not need them.

**2. Create a new API account and copy the key**

Choose Create New Account. The new account appears in the list at the bottom of the page with its API key.

> The key identifies your store, so it is shown on the connection.

**3. Copy the API password from your email**

n11 sends the API password (also called the secret) to the store's registered email address, not to the page.

**4. Paste both in HeyMetra and save**

Saving reads one page of the last day's orders. A green connection means the store answered.

The same steps are on the docs page: [n11 setup guide](https://heymetra.com/docs/n11/).

## Then add HeyMetra to your assistant

Add HeyMetra once and it is there in every conversation. The address is the same everywhere:

```
https://mcp.heymetra.com/mcp
```

### One command

```bash
npx add-mcp https://mcp.heymetra.com/mcp
```

[`add-mcp`](https://www.npmjs.com/package/add-mcp) is a third-party installer that writes the configuration for Claude Code, Codex, Cursor, Antigravity, VS Code and seventeen other agents. It infers the name from the address, so the server lands as `heymetra`. Run against this endpoint before it was written here.

## What it may and may not touch

Propose a change to this account. Nothing is sent until you approve it, and HeyMetra cannot undo it afterwards.

Permissions are switched on per connection, and one you leave off is a tool your assistant never sees.

| Permission | What it covers | Changes anything? |
|---|---|---|
| **Full account access** | Lets your assistant read anything in this account to answer your questions. The figures are the provider's own, not ones HeyMetra has checked. It can also propose changes: none is applied until you approve it, and HeyMetra cannot undo one afterwards. | Yes — every change waits for your approval |

<details>
<summary>What each permission lets an assistant do, in full</summary>

- Ask anything about this account and get the answer from its live data. Reads only, and the figures are the provider's own rather than ones HeyMetra has checked.
- Propose a change to this account. Nothing is sent until you approve it, and HeyMetra cannot undo it afterwards.
</details>

Anything that would change something comes back as a proposal you approve. Nothing is applied before your yes, and only on an account you connected with permission to change it. [How that works](https://heymetra.com/security/).

## When something goes wrong

<details>
<summary>Saving fails with an authorisation error.</summary>

**Why:** The key and the password are in each other's boxes, or the password was renewed.

**Fix:** Check which value is which and paste the newest password from n11's email.

</details>

## What HeyMetra reads from n11

Connect the store with the API key and password from the n11 Seller Office, then ask about it from your assistant: shipment packages for a period with status, line prices, discounts and commission rates; your products with price and stock; return and cancellation requests; and customer questions. When you connect, you choose whether your assistant may also propose changes, such as a price, an answer to a question or a decision on a return, and every change it proposes waits until you approve it.
